# Фронтенд модерации

## Обзор

Фронтенд модерации поддерживает новый статус `DISCREPANT` и вебсокет для реального времени. Страница находится в `src/pages/Admin/ui/ModerationPage.tsx`.

## Новые возможности

### 1. Статус DISCREPANT
- Новый статус для отметки некорректных данных
- Пользователь может исправить данные и отправить повторно
- Данные не очищаются

### 2. Вебсокет модерация
- Реальное время обновления статусов
- Автоматическое переподключение
- Fallback на HTTP API при недоступности вебсокета

### 3. Модальное окно действий
- Единое окно для всех типов действий
- Поле для указания причины
- Чекбокс для бана пользователя (только для отклонения)

## Компоненты

### ModerationPage
Основная страница модерации с:
- Списком элементов для модерации
- Фильтрами по статусу и типу
- Пагинацией
- Модальными окнами для деталей и действий

### useModerationWebSocket
Хук для работы с вебсокетом модерации:
- Автоматическое подключение
- Обработка сообщений
- Переподключение при разрыве

## Действия модерации

### APPROVE - Одобрение
- Анкета одобрена
- Статус профиля обновляется
- Пользователь получает уведомление

### REJECT - Отклонение (два пути)
1. **Без бана**: данные очищаются, пользователь может заполнить заново
2. **С баном**: пользователь блокируется

### DISCREPANT - Некорректные данные
- Данные не очищаются
- Пользователь получает описание проблемы
- Может исправить и отправить повторно

## API интеграция

### HTTP API (fallback)
- `GET /api/moderation/items` - список элементов
- `POST /api/moderation/item/status` - обновление статуса
- `GET /api/moderation/stats` - статистика

### WebSocket API
- `ws://localhost:3001/ws/moderation` - подключение
- `action` - отправка действия модерации
- `action_success` - подтверждение успешного действия
- `error` - ошибки

## Типы данных

```typescript
interface ModerationAction {
  itemId: string
  action: 'APPROVE' | 'REJECT' | 'DISCREPANT'
  reason?: string
  banUser?: boolean
}

interface ModerationWebSocketMessage {
  ch: string
  t: string
  cid?: string
  data?: any
}
```

## Использование

### Подключение вебсокета
```typescript
const { sendAction, isConnected } = useModerationWebSocket(
  (data) => {
    // Обработка успешного действия
    console.log('Action successful:', data)
  },
  (message) => {
    // Обработка ошибок
    console.error('WebSocket error:', message)
  }
)
```

### Отправка действия
```typescript
sendAction({
  itemId: 'abc123',
  action: 'REJECT',
  reason: 'Нарушение правил',
  banUser: true
})
```

## Стилизация

Используются CSS переменные для темной/светлой темы:
- `--color-fg` - основной текст
- `--color-fg-secondary` - вторичный текст
- `--color-bg` - основной фон
- `--color-bg-secondary` - вторичный фон
- `--color-border` - границы
- `--color-accent` - акцентный цвет

## Состояния

- **PENDING** - ожидает модерации (синий)
- **APPROVED** - одобрено (зеленый)
- **REJECTED** - отклонено (красный)
- **DISCREPANT** - некорректные данные (желтый)

## Индикаторы

- Статус вебсокета (зеленая/красная точка)
- Цветовая кодировка статусов
- Иконки для действий (галочка, крестик, восклицательный знак)
